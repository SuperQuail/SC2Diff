# v0.1.0

首个可运行版本：**星际争霸 II 地图/依赖的语义 diff 与版本控制**。

## 包含什么

- **容器层**：MPQ format-3 文档的完整读写（头部摘要块、HET/BET、attributes、bzip2/zlib 压缩、
  单块与分扇区布局）。判据是逐字节可复现：HET/BET 重生成与原件逐字节相同，组件往返逐字节相同。
- **语义 diff**：按身份键（物件 Id / 触发器 Id / 目录 标签+id / 本地化键）做有序无关比较，
  XML 被整体重写也只报真正的变化。
- **git 形状的版本控制**：init / add / status / diff / commit / log / show / branch / checkout /
  switch / tag / restore / rm / ls-files，含暂存区、引用、detached HEAD、HEAD~n。
- **补丁包交换**：bundle / apply，一个 zip 走现有渠道（网盘、群文件、共享目录），
  --basis 生成瘦补丁（实测：44 MB 战役包改一个组件 -> 0.02 MB）。
- **重新封装**：pack 产出的 .SC2Map 经银河编辑器 A/B 验收可正常打开。

## 性能

175 MB 工作树 / 299 个组件：scan 172 ms -> 20 ms，status 172 ms -> 19 ms，
diff 171 ms -> 28 ms，init 10.1 s -> 5.7 s。

## 注意

- 本仓库**不含任何游戏资源**；测试用 tools/fixture.py 生成合成文档。
- `tools/editor_accept.py` 需要本机安装星际争霸 II 编辑器，因此不进 CI。
- 合并（merge）与远端尚未实现，计划见 docs/collaboration-plan.md。
