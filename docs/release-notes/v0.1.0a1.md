# 0.1.0a1 （测试版 / pre-release）

> 这是**预发布**：用来验证打包与发布链路，API 与命令仍可能变动。

## 这一版是什么

星际争霸 II 地图/依赖的**语义 diff** 与 **git 形状的版本控制**，以及能产出
编辑器可直接打开的归档。

## 包含

- **容器层**：MPQ format-3 文档完整读写（头部摘要块、HET/BET、(attributes)、
  bzip2/zlib、单块与分扇区布局）。判据是逐字节可复现：
  HET/BET 重生成与原件逐字节相同，组件往返逐字节相同（真实样本 5/5）。
- **语义 diff**：按身份键（物件 Id / 触发器 Id / 目录 标签+id / 本地化键）做有序无关比较。
  XML 被整体重写也只报真正的变化 —— 实测删一个物件 + 改一个字段只输出两行。
- **git 形状的 CLI**：init / add / rm / status / diff / commit / log / show / branch /
  checkout / switch / tag / restore / ls-files，含暂存区、引用、detached HEAD、HEAD~n。
- **补丁包交换**：bundle / apply。一个 zip，走网盘、群文件、共享目录，无需任何服务端；
  --basis 生成瘦补丁（44 MB 战役包改一个组件 -> 0.02 MB）。
- **重新封装**：pack 产出的 .SC2Map 经银河编辑器 A/B 验收可正常打开。

## 性能（175 MB 工作树 / 299 个组件）

| 操作 | 优化前 | 优化后 |
| --- | --- | --- |
| scan | 172 ms | 20 ms |
| status | 172 ms | 19 ms |
| diff（干净树） | 171 ms | 28 ms |
| init（解包+首提交） | 10.1 s | 5.7 s |

## 已知限制（本版明确不含）

- **没有合并（merge）**：两条分支都改同一处时无法自动整合，目前只能人工取舍。
  这是协作链路上真正缺的一环，计划见 docs/collaboration-plan.md。
- **没有远端协议**：不做 push/pull/clone；改用补丁包交换（bundle/apply）。
- 二进制组件（DocumentHeader / MapInfo / t3*）只能报「已变化 + 哈希」，无字段级 diff。
- 仓库存储无 delta 压缩，同一组件多次改动会各存一份完整 blobs。

## 本仓库不含游戏资源

测试数据由 tools/fixture.py 现场生成合成文档，CI 不依赖星际争霸 II 安装，
也不依赖任何社区战役包。
