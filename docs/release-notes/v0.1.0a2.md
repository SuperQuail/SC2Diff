# 0.1.0a2 （测试版 / pre-release）

> 预发布：用来验证 Rust 交付与发布链路。API 与命令仍可能变动。

## 最重要的变化：产品改用 Rust 实现

按既定分工 —— **Python 做技术验证，Rust 做实际产品** —— 本版把实现搬到了 Rust，
并且**附件里带编译好的 CLI**（不再只有源码）。

| 角色 | 位置 |
| --- | --- |
| **产品** | `src/`（Rust，编译出单文件 `sc2diff.exe`） |
| 验证与判据 | `tools/`（Python，保留为差分测试的 oracle） |

Python 那套是**格式事实的来源**：HET/BET 布局、`dwRawChunkSize` 必须为 0、头部摘要块、
`(attributes)` 约定，都是从它逐字节验证出来的；Rust 是这些结论的落地实现。

## 附件

- `sc2diff.exe` —— Windows x64 单文件 CLI，无运行时依赖
- `sc2diff-v0.1.0a2.zip` —— 源码 + 文档 + 该 exe

## Rust 版包含

- **容器层**：MPQ format-3 文档完整读写（头部摘要块、HET/BET、`(attributes)`、
  bzip2/zlib、单块与分扇区）。判据是逐字节可复现。
- **语义 diff**：身份键模型（物件 Id / 触发器 Id / 目录 标签+id / 本地化键），有序无关。
- **git 形状 CLI**：init / add / rm / status / diff / commit / log / show / branch /
  checkout / switch / tag / restore / ls-files / unpack / pack / bundle / apply / verify。
- **补丁包交换**：bundle / apply，一个 zip 走现有渠道，无需服务端。

## 验收（本版实测）

| 判据 | 结果 |
| --- | --- |
| `cargo test --release` | 6/6 通过 |
| Python 读 Rust 产物 | 摘要块全部 valid，HET/BET **按 Rust 字节**逐字节重生成一致 |
| **银河编辑器打开 Rust 打包的地图** | **LOADED** |

## 已知限制

- **没有合并（merge）**：两条分支改同一处仍需人工取舍。
- **没有远端协议**：改用补丁包交换（bundle/apply）。
- 二进制组件只能报「已变化 + 哈希」，无字段级 diff。
- 仓库无 delta 压缩。
